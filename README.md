# MH: Recomp
Play the classic Monster Hunter saga better than ever!

# Introduction (original game)
Monster Hunter Freedom is a 2005 action role-playing game developed and published by Capcom for the PlayStation Portable. The first handheld installment in the Monster Hunter franchise, the game is an enhanced port of Monster Hunter G, rebalanced to allow for easier solo quest completion and game progression.

# Enhancements
• 60, 90, 120, and higher FPS: Play at high frame rates so you don't miss a single frame of the action (frame rates above 200 may break the game)
• Ultrawide display: Play in 4:3, 16:9, 13:6, 21:9, and more
• Flexible controls: Play using a PlayStation controller, touch controls, keyboard and mouse, or a gamepad (Xbox or generic)
• Dual-screen setup: Use the second screen to view the action just like on the Nintendo 3DS (AYN Thor exclusive)
